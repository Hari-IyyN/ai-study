# AI Fundamentals — Tokens

## 1. What is a Token?
- A small unit of text processed by an LLM.
- Can be a word, part of a word, character, punctuation, or text fragment.
- LLMs process tokens rather than complete sentences directly.

## 2. Simple Flow
```text
User Text
   ↓
Tokenization
   ↓
Tokens
   ↓
LLM
   ↓
Output Tokens
   ↓
Text Response
```

## 3. Tokenization
- Converts text into tokens.
- Tokenizers decide how text is split.
- Different models can use different tokenizers.
- The same text can produce different token counts with different models.

## 4. Input Tokens
- Tokens sent to the model.
- Can include:
  - User prompt
  - System instructions
  - Developer instructions
  - Conversation history
  - RAG context
  - Tool-related context

## 5. Output Tokens
- Tokens generated by the model.
- These tokens form the final response.

## 6. Total Tokens
```text
Total Tokens = Input Tokens + Output Tokens
```
Important for:
- Cost
- Context limits
- Performance

## 7. Context Window
- Maximum amount of context a model can handle.
- Can include instructions, user messages, history, RAG context, and output.

```text
Context Window
├── Instructions
├── User Message
├── Chat History
├── RAG Context
└── Output
```

## 8. Why Tokens Matter in an AI Chatbot
- Controls how much information can be sent.
- Affects API cost.
- Affects response limits.
- Important for chat history.
- Important for RAG.
- Important for long documents.
- Important for prompt design.

## 9. Tokens & Chat History
```text
More Chat History
       ↓
More Input Tokens
       ↓
Higher Context Usage
       ↓
Potentially Higher Cost
```
Common approaches:
- Limit history
- Summarize old messages
- Retrieve relevant messages
- Use memory strategically

## 10. Tokens & RAG
```text
User Question
      ↓
Retrieved Documents
      ↓
Context
      ↓
LLM
```
- Retrieved content consumes input tokens.
- Too much context can waste tokens.
- Good chunking and retrieval are important.

## 11. Tokens & Cost
- More input tokens → more input usage.
- More output tokens → more output usage.
- Pricing depends on model/provider.
- Free models can also have token/rate limits.

## 12. Max Output Tokens
- Controls the maximum output the model can generate.
- The model does not necessarily generate that many tokens.
- Very high limits can affect cost or availability depending on the provider.

## 13. Token Limits vs Context Window
### Token Limit
- Limit applied to a request or output.

### Context Window
- Total context the model can work with.

```text
Context Window
├── Input
└── Output
```
