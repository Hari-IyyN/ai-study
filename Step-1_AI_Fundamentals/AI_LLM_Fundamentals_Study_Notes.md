# AI & LLM Fundamentals -- Study Notes

## 1. Inference

**Inference** is the process of using a trained AI/ML model to generate
a prediction or response for new input.

### Simple Flow

``` text
User Input
   ↓
Trained Model
   ↓
Inference
   ↓
Prediction / Response
```

------------------------------------------------------------------------

## 2. Training vs Inference

### Training

Training is when the model **learns patterns from data**.

``` text
Training Data
     ↓
   Model
     ↓
Learn Patterns
     ↓
Trained Model
```

### Inference

Inference is when we **use the trained model** to generate an output.

``` text
User Input
    ↓
Trained Model
    ↓
Inference
    ↓
Output
```

### Simple Difference

  -----------------------------------------------------------------------
  Training                            Inference
  ----------------------------------- -----------------------------------
  Model learns                        Model generates

  Uses training data                  Uses new input

  Happens during model development    Happens when using the model

  Usually computationally expensive   Usually optimized for serving
                                      responses
  -----------------------------------------------------------------------

## 3. Transformer Basics

A **Transformer** is a neural network architecture widely used in modern
LLMs.

The main idea is **attention**, which helps the model understand
relationships between tokens in the input.

### Simple Flow

``` text
Text
 ↓
Tokenization
 ↓
Tokens
 ↓
Embeddings
 ↓
Transformer Layers
 ↓
Attention
 ↓
Output
```

### Attention

Attention helps the model determine which parts of the input are
important in relation to other parts.

### Important Concepts

-   Tokens
-   Embeddings
-   Attention
-   Self-Attention
-   Transformer Layers
-   Positional Information

## 4. Hallucination

**Hallucination** happens when an AI model generates information that
sounds correct but is **incorrect, unsupported, or fabricated**.

### Example

A model may confidently provide an answer to a question even when the
information is unknown or unsupported.

### Why It Happens

-   The model generates based on learned patterns.
-   It does not automatically verify every statement.
-   The available context may be incomplete.
-   The question may be ambiguous.
-   The model can generate plausible but incorrect information.

### How to Reduce Hallucination

-   Provide good context.
-   Use RAG when appropriate.
-   Use reliable data sources.
-   Ask the model to state uncertainty.
-   Validate important outputs.
-   Use tools/search when factual verification is required.

## 5. Model Limitations

AI/LLM models have limitations that we need to understand before using
them in production.

### Common Limitations

-   **Knowledge limitations** -- The model may not know recent or
    private information.
-   **Hallucinations** -- The model can generate incorrect information.
-   **Context window** -- The model can only process a limited amount of
    context at once.
-   **Reasoning limitations** -- Complex reasoning can still produce
    incorrect results.
-   **Training data limitations** -- Model behavior depends on the data
    used to train it.
-   **Bias** -- Models can reflect biases present in their training
    data.
-   **No guaranteed accuracy** -- A confident response does not
    guarantee that it is correct.

### Production Mindset

``` text
LLM Output
    ↓
Validate
    ↓
Verify when required
    ↓
Use in Application
```
